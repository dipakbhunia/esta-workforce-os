## Status legend

- **IMPLEMENTED AND VERIFIED** — implementation plus reviewed test/checkpoint evidence.
- **PARTIALLY IMPLEMENTED** — material working scope exists but approved work remains.
- **FOUNDATION ONLY** — enabling architecture exists without the full workflow.
- **PLANNED** — approved vision/roadmap item without functional implementation.
- **DEFERRED** — intentionally blocked on an approved dependency or phase.
- **NOT VERIFIED** — implementation or release evidence is insufficient.
