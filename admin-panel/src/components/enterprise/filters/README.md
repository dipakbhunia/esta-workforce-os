# Enterprise Filter System

Reusable filter card primitives for enterprise list pages.

Use `EnterpriseFilterCard` with:
- `search` for one authoritative server-side search control.
- `filters` for page-owned filter controls.
- `actions` for reset, refresh, export, or add actions.
- `activeFilters` for removable chips.
- `summary` for server pagination counts.

Keep business rules in the feature page. These components only manage layout,
hierarchy, responsive spacing, and accessibility affordances.
